# Car Price Prediction

## Project Overview

This project predicts the selling price of a used car based on various features such as brand, fuel type, ownership, kilometers driven, and other relevant factors.

## Problem Statement

The objective of this project is to build a machine learning regression model that can estimate the selling price of a used car.

## Dataset

The dataset contains information about used cars, including:

- Brand
- Fuel
- Owner
- Kilometers Driven
- Selling Price

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning

The project includes:

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Categorical Encoding
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Model Saving

## Model

The trained model is saved as:

`model.pkl`

## Evaluation

The model is evaluated using regression metrics such as:

- R² Score
- Mean Absolute Error
- Mean Squared Error
- Root Mean Squared Error
